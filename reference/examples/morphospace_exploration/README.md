# Morphospace starting states

These nine EmbryoMaker snapshots are starting states included in the
Morphospace Exploration repository. They are available in EmbryoMaker Studio
and through the EmbryoMaker MCP server.

Source: [HugoCanoFernandez/Morphospace_exploration_EMaker](https://github.com/HugoCanoFernandez/Morphospace_exploration_EMaker)

The Figure 7 folder contains `Figure_7A.dat` through `Figure_7F.dat`. The
Figure 8 folder contains `Figure_4D.dat` through `Figure_4F.dat`. The original
repository says these files are the initial conditions for the simulations
shown in the corresponding figures.

Paper: Hugo Cano-Fernandez, Miguel Brun-Usan, Tazzio Tissot, and Isaac
Salazar-Ciudad, "A Morphospace Exploration Using a General Model of
Development Reveals a Basic Set of Morphologies for Early Animal Development
and Evolution," *Journal of Experimental Zoology Part B*, 344 (2025), 45-58.
[doi:10.1002/jez.b.23279](https://doi.org/10.1002/jez.b.23279).
